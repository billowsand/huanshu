# 幻述原生界面验证文档

这份文档由 `spikes/gpui-kit/assets/sample.md` 的生成脚本产出，用来在 GPUI Kit 的多行编辑器里验证滚动、软换行、选择、输入法与撤销重做。全文约一万字符，中英混排。

## 第 1 章 · 渲染与界面

### 1.1 小节标题

Typst 的 comemo 缓存只增不减，必须在每次编译之后主动淘汰，否则长时间编辑会把内存吃光。候选项框、下划线的未上屏文本、标点全半角，这三件事决定了中文用户能不能舒服地写文档。GPUI 在 Windows 上通过 ImmSetCompositionWindow 通知输入法把候选框放到光标的位置。Release build matters: 只有优化过的构建才能给出可信的延迟数字，debug 下的耗时只能说明 debug。

Release build matters: 只有优化过的构建才能给出可信的延迟数字，debug 下的耗时只能说明 debug。缩略图的宽度按 64 像素取整，宽度档位变化才重新光栅化，否则每一次窗口拖动都会触发整副牌重渲。The renderer keeps one font store per process, and scanning the system fonts costs about half a second.一次请求里只包含变化的页面：整批丢弃会让上一批的页面永远等不到图。标题改一个字就要重排整页，因为自动缩放会重新测量所有文本块。
