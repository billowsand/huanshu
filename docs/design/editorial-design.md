# 报刊·钴蓝：现代报刊版式

依据 2026-10-16 确认的 ImageGen 预览实施。参考方向是暖白纸面、粗黑标题、钴蓝重点、细线分栏与方角控件。

## 配色与层级

| 用途 | 色值 |
| --- | --- |
| 纸面 | `#f6f5f0` |
| 界面卡片 | `#ffffff` |
| 墨色 | `#141414` |
| 次要文字 | `#73736f` |
| 分隔线 | `#d8d6cf` |
| 钴蓝 | `#2549d8` |
| 浅蓝选区 | `#e9edfc` |

主操作用黑底白字，悬停变为钴蓝；选区、链接、焦点仍使用钴蓝。状态色保留各自语义，不使用参考图中的红黄装饰替代状态颜色。

## 首页

- 刊头式标题「我的演示文稿」，「演示」用钴蓝，旁边显示真实项目数。
- 内容最大宽度 1232px，包含左右各 24px 留白；内容区达到 940px 时切换双列，否则单列。
- 方角项目卡片高 112px。左侧为根据项目名称与页数排出的文字封面，不冒充真实第一页缩略图；导出、删除、导入、新建和主题切换沿用现有行为。
- 空状态与加载状态沿用原有功能；主题之外的页面密度不变。便签主题的既有修改保留。
- Vue 和 GPUI 使用同一配色、相同的主要层级与双列规则。

## 幻灯片

- 所有页面统一 3px 钴蓝顶线，底部细线、品牌和真实页码。
- 封面采用左侧大标题与右侧描边编号；内容较长时使用原有测量收缩机制。标题中的全角逗号、冒号等分隔符继续触发双色标题。
- 标题和数字加粗，正文保留正常字重；内容页副标题为灰色文字，不再铺整条浅蓝底。
- 共用卡片、目录卡片采用上方细线；成果页与图表页用竖线组织列。
- 不增加新的幻灯片字段或改变用户文稿。预览与 PDF 都由同一份 Typst 模板绘制。

## 实现入口

- `src/themes/editorial.css`、`src/themes/catalog.ts`：Vue 外壳与主题选项。
- `apps/huanshu-native/src/theme/{tokens,editor,mod}.rs`：原生配色、编辑器、控件主题。
- `apps/huanshu-native/src/pages/home.rs`、`src/views/HomeView.vue`：首页结构。
- `crates/slide-typst/typst/themes/light-editorial.typ`：幻灯片配色。
- `crates/slide-typst/typst/{main,lib/components,layouts/cover}.typ`：页脚、文字、封面。
