# 原生版终端主题第一版

仅应用于 `apps/huanshu-native`，未改动 Tauri / Vue 界面。

- 项目首页：编号索引表、单击选择、双击或按钮打开、项目详情栏；保留导入、导出和删除。
- 工作流：方角编号导航、终端面板标题和真实状态栏。
- 素材准备：源文件式编辑窗格标题、方角参数与预览面板。
- AI 生成：虚拟任务列表、文字与符号状态、右侧预览和原有重试入口；底部展示最新三条单行日志摘要，完整错误保留在详情。
- 编辑完善：方角分栏、属性面板、页码及保存状态。
- 设置与弹窗：平面矩形控件、配置标题、终端主题专属缩略图与方角导出选项。

截图来自独立的 `target/terminal-design-home` 演示数据。此次只核对布局、主题切换和已有控件入口，未运行真实模型生成或执行删除、导出操作。
