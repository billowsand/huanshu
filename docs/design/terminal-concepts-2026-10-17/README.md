# 终端系列主题方向稿

使用内置 imagegen 生成。此轮为概念设计，未修改应用代码。

## 设计目标

终端特色应贯穿布局、组件、信息层级与状态反馈，而非仅替换配色。

- 项目页：文件索引表格、对齐列、选中行、项目详情面板。
- 素材页：源文件标签、行号、分栏预览、参数检查器。
- 生成页：阶段流水线、逐页任务状态、时间戳日志、失败说明及重试入口。
- 编辑页：编号缩略图、中央画布、属性检查器、底部状态栏。
- 设置及弹窗：分类索引、键值式配置、矩形边框、分段操作栏。
- 字体：路径、编号、时间和状态使用等宽字；中文正文保持易读。
- 配色：终端·墨用橄榄炭黑与杏橙；终端·纸用矿物白、墨绿与铁锈色。

## 落地时需校正

图像是视觉提案，不是功能规格。保留现有真实功能、主题名称与数据；图中的版本、日期、路径、主题名、额外导航及控件仅为示意。浅色图中的其他主题名并非现有主题名称。墨色图的山景不属于主题要求；落地时以纯色、细线、字符结构为主，消除装饰渐变与拟物阴影。状态必须同时使用文字和符号，不能仅靠颜色表达。生成中的状态一致性、按钮禁用条件和快捷键应沿用现有业务规则。设置与导出叠加仅用于展示组件语言，不代表新增入口。图像文字可能不准确，实施时使用现有应用文案。
