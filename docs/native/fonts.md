# 原生应用字体覆盖

设置 → 外观与字体管理以下十个用途。主题只控制颜色、字号、行高和稿纸，不覆盖字体选择。

| 设置类别 | 使用位置 |
| --- | --- |
| 界面 | 首页、向导、设置、工作流、演示控制栏、按钮、表单、菜单、弹窗、通知与提示 |
| 编辑器 | 第一步 Markdown 源码与行号；所有主题使用同一设置 |
| 代码与日志 | Markdown 预览代码、生成调试与日志、第三步 JSON 编辑、导出诊断 |
| 标题 | 幻灯片封面、章节、卡片标题 |
| 副标题 | 幻灯片副标题与说明 |
| 正文 | Markdown 文稿预览、幻灯片正文、表格和图表文字 |
| 注释与标签 | 幻灯片标签、脚注、辅助说明 |
| 数字与序号 | 幻灯片编号、步骤、序号与时间轴 |
| 数学公式 | Markdown 预览、幻灯片、导出 PDF 中的公式；选择已安装且受支持的数学字体 |
| 兜底字体 | 所有界面文字与幻灯片文字在首选字体未安装或缺字时优先尝试 |

界面从窗口根层继承缺字回退列表，弹层与提示也在覆盖范围内。首选字体未安装时先选择用户兜底，再尝试系统默认字体。Kit 与 Base 的主题投影同步，富文本中的代码块不会停留在旧字体。

幻灯片缩略图、编辑预览、全屏演示与 PDF 共用 core → Typst 的字体列表：用途字体 → 用户兜底 → 内置中文回退 → 排版引擎系统回退。公式先用所选数学字体与其他可用数学字体，文字部分继续使用正文与兜底字体。字体配置已进入幻灯片和公式缓存键，保存更改后不会沿用旧字体图片。

“统一所有字体”同步八种文字用途；数学公式与兜底字体独立设置。旧设置缺少新增字段时自动填入默认值，仍可读取。图片和图标资源中已经固化的字形不属于应用可排版文字。

验证覆盖设置兼容与序列化、全部六种幻灯片文字角色的兜底顺序、缺失首选字体的全版式渲染、公式渲染、原生设置的统一/重置行为。
