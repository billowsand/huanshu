# DMXAPI qwen3.8-flash 实测（2026-10-19）

结论：接口适配、不思考请求、并发生成、编辑存储与 Typst 渲染检查通过；自由文本图表解读仍有少量事实错误，不能判定内容质量全部通过。

## 接口与不思考约束

- 从用户指定的 `model_api_test.md.txt` 读取 DMXAPI 地址与密钥，仅用于该服务；没有修改用户正常设置或保存密钥到测试配置。
- 文本生成、页面规划、修复、重试和图片理解均使用 `qwen3.8-flash`；向量接口独立使用 `text-embedding-3-small`，实测维度 1536。
- Qwen 云端 HTTP 请求使用顶层 `enable_thinking: false` 和 `stream: false`，不发送 `reasoning_effort`，不使用 thinking 模式。[DMXAPI 参数文档](https://doc.dmxapi.cn/thinking-qwen.html)
- 本地 LM Studio 仍携带 `chat_template_kwargs.enable_thinking: false`；不把本地模板参数当作云端关闭思考的依据。
- 文本和视觉返回统一检查 `reasoning_content`、`reasoning`、思考标签及服务提供的 reasoning token 数；若发现思考返回则报错，不静默丢弃后当作成功。
- 支持地址末尾有或没有 `/v1`，避免重复拼接。向量请求按 128 条分批，按响应 index 对齐原始输入，校验数量、索引及维度。
- 界面并发设置范围调整为 1–32，允许设置本次实测的 8 和 12；默认设置及用户数据没有被改写。

## 真实测试结果

| 场景 | 结果 |
|---|---|
| 并发配置 8：20 个内容样例，覆盖全部内容版式、五类图表与 spotlight 四种面板 | 组装后 23 页，通过；耗时 59.0 秒 |
| 并发配置 12：重复全部 20 个内容样例 | 组装后 23 页，通过；耗时 70.0 秒；请求实测峰值 8 路同时在途 |
| 完整 Markdown→嵌入缓存→页面规划→版式分配→生成→组装→保存 | 18 个内容页、21 页完整文稿，通过；295.8 秒，包含首次计算 2634 个图标向量；请求实测峰值 8 |
| 完整生成记录上的单页重试 | 通过；35.2 秒；原始图表和其他 20 页不变 |
| 用户反馈修复 process 与 chart_focus | 通过；20.1 秒；阶段副标题和 summary 可回写，图表与章节保留，修复遵循项目选定比例 |
| 图片理解接口 | 通过；1.7 秒；识别出四层数据平台架构 |

每套文稿均验证：严格字段契约、JSON typed 往返、编辑回写不丢其他字段、项目保存后读回一致、6 主题 × 3 比例的 PDF 与预览位图。18 种渲染组合均无页数差异、溢出或缺图报告；抽查真实生成的 PNG，图片和结构化面板可见。

两轮 matrix 没有触发整页兜底。12 路测试中 process 首次回答不符合契约，一次带错误反馈的重试成功；保留原始错误与更正回答，未通过删字段或换版式掩盖错误。

合计记录 96 次真实聊天/视觉请求与 96 次响应；96 次请求均设置 `enable_thinking: false`，响应中未检测到思考内容。服务未报告的隐藏内部计算无法由客户端检查，此结论限于请求参数和实际可观察的返回。

核心自动测试 228 项通过、1 项既有手动探针忽略；原生界面并发边界测试通过。新增测试覆盖云端/本地关闭思考参数、`/v1` 地址规范化、拒绝思考返回及允许空推理字段。

## 仍存在的内容问题

8 路样例中五种图表的极值、占比、增量、增速方向人工复核正常；12 路复测仍出现以下错误：

- `matrix12/chart-donut/final.json`：24 与 12 实际恰好相差一倍，模型写成“两者相差一倍以上”。
- `matrix12/chart-stacked_area/final.json`：50% 是二季度相对一季度的增长率，模型仍将其称为“一季度的 50%”。

此外，圆环标签现有最大余数法要求两位小数合计 100%，该样例显示 44.45%；按单项四舍五入的正文显示 44.44%。展示口径尚未统一。这些不是 schema 校验可以发现的错误，本次没有把语义检查记为全部通过，也没有通过覆盖模型输出隐藏问题。
